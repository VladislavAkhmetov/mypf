# Журнал

Окно «Журнал» открывается из виджета на рабочем столе, из меню «Пуск» и по ссылке `/?view=notes`. Ссылка на конкретную запись: `/?view=notes&note=ID`, где ID — имя файла без даты и расширения.

Иконка журнала на рабочем столе скрыта, в меню «Пуск» он остаётся. Списки скрытых приложений лежат в `src/lib/xp/hidden-apps.ts`.

## Как добавить запись (2 минуты)

1. Скопируйте `content/journal/_template.md` в `content/journal/ГГГГ-ММ-ДД-короткое-имя.md`.
2. Заполните шапку и напишите текст.
3. Картинки и видео положите в `public/images/journal/` и вставьте в текст.
4. Выполните `npm run journal`, чтобы обновить данные в превью. Перед `npm run build` и деплоем это делается автоматически.

Если что-то указано неверно (нет файла, неизвестный проект, не указана дата), скрипт остановится и скажет, что именно исправить.

## Формат файла

```md
---
title: Заголовок записи
date: 2026-10-08
project: dombro
---
Абзац текста. **Жирный**, *курсив*, `код`, [ссылка](https://example.com).

![Подпись под картинкой](/images/journal/screen.webp)

## Подзаголовок

- пункт списка
- ещё пункт

![Было](/images/journal/before.webp)
![Стало](/images/journal/after.webp)
```

- `title` и `date` обязательны. `project` (`dombro`, `tasker`, `kroomi`) необязателен: если указан, внизу появится кнопка «Смотреть проект» и цветной акцент.
- Абзацы разделяются пустой строкой.
- Подпись в квадратных скобках у картинки показывается под ней и служит описанием для скринридеров, поэтому её лучше не оставлять пустой.
- Несколько картинок подряд без пустой строки встают в ряд (до трёх). Видео (`.mp4`, `.webm`) вставляется тем же синтаксисом.
- Время чтения считается автоматически, записи группируются по месяцам, новые сверху.
- Файлы, имя которых начинается с `_`, пропускаются (черновики и шаблон).

## Статьи из справки

Справочные материалы можно писать здесь же. Без `project` запись просто остаётся заметкой без кнопки.

## Как это устроено

`scripts/build-journal.mjs` читает `content/journal/*.md` и создаёт `src/data/journal.generated.ts`. Этот файл лежит в репозитории, его не нужно править вручную. Лента (`src/components/notes/notes-feed.tsx`) и виджет рабочего стола читают данные из `src/data/notes.ts`.

Лайков, комментариев и закладок в журнале нет.
