# Микроблог «Заметки»

Лента: `/?view=notes`. Отдельная запись: `/?view=notes&note=ID`.
Открывается в самостоятельном узком окне «Личный журнал», не внутри портфолио.
Новые записи сверху. На десктопе справа расположен виджет: последняя запись с медиа
и начало предыдущей. Окна, включая портфолио, перекрывают виджет — место под него
не резервируется. На узких экранах вход через иконку «Заметки» или меню «Пуск».
При раскрытии журнала виджет скрывается; при закрытии или сворачивании появляется снова.

## Публикация

Редактируйте `src/data/notes.ts`. Это общий публичный контент, попадающий на сайт
при следующем деплое. Сейчас записи отмечены `demo: true`: тексты — примеры,
не биографические утверждения. Замените их на свои и удалите флаг `demo`.

Каждая запись содержит:

- `id`: постоянный уникальный идентификатор для ссылок;
- `date`: дата ISO с часовым поясом, например `2026-09-22T12:00:00+03:00`;
- `category`: «Проекты», «Путешествия» или «Эксперименты»;
- `text`: текст, `\n\n` разделяет абзацы;
- `media`: необязательная галерея `{ type: "image", src: "/notes/photo.jpg", alt: "Описание" }`;
- видео: `{ type: "video", src: "/notes/process.mp4", poster: "/notes/poster.jpg", alt: "Описание" }`;
- `projectSlug`: необязательная ссылка на существующий кейс;
- `continuation`: массив продолжений ветки `{ id, text, media? }`.

Медиа удобно хранить в `public/notes/` (создайте каталог при добавлении файлов).
Посты автоматически сортируются по дате. Не меняйте ID опубликованных записей,
чтобы не ломать ссылки. Аватар и контакты берутся из `src/data/site.ts`.

## Что сохраняется локально

Лайки и закладки — личные отметки без общих счётчиков, в localStorage посетителя.
Публичных комментариев, аккаунтов посетителей и административного редактора нет.
Кнопка ответа открывает Telegram автора; сайт ничего не отправляет от посетителя.
Для публикации через браузер понадобится серверное хранилище и авторизация владельца.
