# Микроблог «Заметки» (стиль Threads)

Лента: `/?view=notes`. Отдельная ветка: `/?view=notes&note=ID`.
Открывается в окне «Личный журнал / Заметки» в стилистике персонального **Threads** с плавными iOS-анимациями (`beUI` / `motion`).

## Особенности интерфейса Threads

- **Чистый визуал**: Глубокий тёмный фон (`#101010`), контрастная типографика, отсутствие лишних служебных плашек («Демо», «Новые записи — сверху»).
- **Аутентичный профиль**: Крупное имя автора, никнейм `@amazi` с синей галочкой верификации **Verified**, аватар и кнопки («Портфолио ↗», «Написать мне ↗»).
- **Плавные iOS-переключатели (`beUI`)**: Вкладки категорий («Все», «Проекты», «Путешествия», «Эксперименты») со скользящей плашкой (`layoutId="activeCategoryPill"`), пружинной физикой `motion/react`.
- **Ветка и нить связности (Thread Line)**: Тонкая вертикальная линия, связывающая аватар автора с комментариями и продолжениями записи.
- **Интерактивные действия**:
  - ❤️ **Лайк**: Bouncy spring-поп анимация, счётчик в реальном времени.
  - 💬 **Комментарии**: Плавное раскрытие ветки комментариев (`AnimatePresence`) и форма ответа.
  - ✈️ **Поделиться**: Копирование прямой ссылки на тред в буфер.
  - 🔖 **Сохранить**: Добавление в локальные закладки.
  - **Без перетвитов**: Лента остаётся личным, чистым пространством автора.
- **Dynamic Island Toast**: Уведомление о копировании ссылки в виде парящей капсулы iOS с мягким размытием.

## Публикация заметок

Редактируйте `src/data/notes.ts`. Записи автоматически сортируются по дате (новые сверху):

- `id`: уникальный постоянный идентификатор для ссылок;
- `date`: дата ISO с часовым поясом (`2026-09-22T12:00:00+03:00`);
- `category`: «Проекты», «Путешествия» или «Эксперименты»;
- `text`: текст записи;
- `media`: галерея `{ type: "image", src: "...", alt: "..." }` или видео;
- `projectSlug`: ссылка на кейс в портфолио;
- `continuation`: массив продолжений ветки `{ id, text, media? }`.

## Лайки и комментарии: архитектура и онлайн

Состояние управляется модулем `src/lib/notes/threads-store.ts`:

1. **Сейчас (Hybrid / Optimistic)**:
   - Лайки, закладки и добавленные комментарии мгновенно сохраняются в браузере гостя (`localStorage`).
   - Присутствуют стартовые комментарии и счётчики для живого ощущения ленты.
2. **Как переключить на общий глобальный онлайн (для всех)**:
   - Рекомендуемый бесплатный сервис: **[Supabase](https://supabase.com)** (PostgreSQL + Realtime).
   - Создаются две таблицы:
     - `note_likes (note_id text, client_id text, created_at timestamptz)`
     - `note_comments (id text, note_id text, author_name text, author_handle text, text text, created_at timestamptz)`
   - В `src/lib/notes/threads-store.ts` подключается клиент Supabase через `.env.local` (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`). Все комментарии и лайки синхронизируются в реальном времени у всех посетителей.
