# Bliss по времени суток

Используется местное время посетителя. Геолокация не нужна.

| Время | Файл |
| --- | --- |
| 06:00–10:59 | `public/images/wallpapers/bliss-morning.jpg` |
| 11:00–17:59 | `public/images/bliss.jpg` — оригинальный дневной Bliss, уже есть |
| 18:00–21:59 | `public/images/wallpapers/bliss-evening.jpg` |
| 22:00–05:59 | `public/images/wallpapers/bliss-night.jpg` |

Положите три настоящих JPG по указанным путям (не переименованные PNG).
Рекомендуемый размер: 2560×1440 или больше, одинаковые кадрирование и положение холма.
Пока варианта нет или он не загрузился, показывается оригинальный дневной Bliss.
После добавления файлов перезагрузите страницу; на хостинге нужен новый деплой.
Часы проверяются каждые 30 секунд и при возвращении во вкладку.

Ручной выбор в свойствах экрана сохраняется. Кнопка «По времени суток»
и затем «Применить» возвращает автоматическую смену.
