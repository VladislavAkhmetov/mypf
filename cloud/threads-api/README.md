# threads-api: лайки и комментарии журнала

Одна функция Yandex Cloud Functions и бессерверная база YDB. Сам сайт лежит в бакете Object Storage.
Пока функция не подключена, сайт работает как раньше: лайки и комментарии видны только в браузере посетителя.

## 1. База YDB
1. Консоль Yandex Cloud → **Managed Service for YDB** → **Создать базу данных** → тип **Serverless**.
2. Откройте базу → **Навигация** → **Новый SQL-запрос**, вставьте содержимое `schema.yql` и выполните.
3. На странице базы скопируйте **Эндпоинт** (`grpcs://...`) и **Базу данных** (`/ru-central1/...`).

## 2. Сервисный аккаунт
**Identity and Access Management** → **Создать сервисный аккаунт** → роль `ydb.editor`.

## 3. Функция
1. **Cloud Functions** → **Создать функцию** → **Создать версию**, среда **Node.js 18** или новее.
2. Загрузите файлы `index.js` и `package.json` (зависимости установятся сами), точка входа: `index.handler`.
3. Укажите сервисный аккаунт из шага 2 и переменные окружения:
   - `YDB_ENDPOINT`, `YDB_DATABASE`: из шага 1;
   - `ALLOWED_ORIGIN`: адрес сайта, например `https://example.ru`;
   - `MODERATION`: не задавайте, тогда новые комментарии появятся только после одобрения. `off` публикует сразу.
4. В настройках функции включите **Публичная функция** и скопируйте её ссылку `https://functions.yandexcloud.net/...`.

## 4. Подключить к сайту
Перед сборкой задайте адрес функции:

```
NEXT_PUBLIC_THREADS_API_URL=https://functions.yandexcloud.net/<id> npm run build
```

(или запишите эту строку в файл `.env.production.local`). Затем загрузите `out/` в бакет.

## Модерация
Новые комментарии лежат в таблице `comments` с `visible = false`. Одобрить:

```sql
UPDATE comments SET visible = true WHERE id = "c-...";
```

Удалить: `DELETE FROM comments WHERE id = "c-...";`

## Бесплатный объём (в месяц)
Cloud Functions: 1 000 000 вызовов и 10 ГБ×час. YDB: 1 000 000 операций (Request Units) и 1 ГБ хранения.
Для журнала портфолио этого хватает с большим запасом.

Код функции не запускался против настоящей YDB. После развёртывания проверьте: откройте ссылку функции в браузере, должен прийти JSON `{"likes":{},"comments":[]}`.
